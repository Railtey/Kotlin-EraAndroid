## EraAndroid 0.5

eraTHYMKR 을 실제로 끝까지 돌려 보면서 찾은 문제들을 고쳤습니다.
(새 게임·기존 세이브 10개에서 수만 번 자동 플레이, 엔딩까지 확인)

### 게임이 멈추던 문제
- 게임 폴더의 `CSV`, `ERB`, `GameBase.CSV` 처럼 대문자 이름을 못 찾던 문제
- 턴 종료 때 보주 처리에서 오류로 멈추던 문제 (`1p63` 숫자 계산)
- 캐릭터 정렬 메뉴, 게임오버 후 선택지, 약 사용 후, 디버그 메뉴 등에서
  배열 범위를 벗어나 멈추던 문제 → 멈추지 않고 계속 진행합니다

### 화면
- 로그가 가득 차면 화면이 새 내용으로 내려가지 않던 문제
- PRINTC 메뉴(상점, 조교 커맨드 등)가 한 줄에 하나씩만 나오던 문제 → 화면 폭에 맞춰 여러 열로
- 버튼이 여러 개인 줄에서 ×, ○ 같은 표시가 사라지던 문제
- 다운로드/문서 폴더에서 고른 게임 폴더도 열 수 있게
