## EraAndroid 0.4

0.3 에서 바뀌었던 화면을 **원래 UI 로 되돌렸습니다.** 새 Emuera 1824 엔진은 기존 화면 뒤에서 그대로 동작합니다.

### 바뀐 점
- 메뉴, 폰트 크기 조절, 폰트 미리보기, 로딩 화면, 버튼 배치, 입력창 등 0.2 의 UI 복구
- 폰트 크기에 맞춘 한 줄 글자 수·PRINTC 열 계산을 새 엔진에도 적용
- 이미지(PRINT_IMG, HTML_PRINT 의 `<img>`)가 있는 줄은 이미지와 함께 표시
- Android 10 이하 기기에서 저장소 권한 요청

### 알아둘 점
- 배경 이미지(CBG)와 도형(PRINT_RECT 등)은 아직 화면에 표시되지 않습니다
