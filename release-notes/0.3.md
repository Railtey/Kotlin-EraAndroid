## EraAndroid 0.3

게임 엔진을 **Emuera 1.824** 소스 코드를 코틀린으로 옮긴 것으로 통째로 교체했습니다.

### 바뀐 점
- 원본 Emuera 와 같은 방식으로 ERB/CSV 를 읽고 실행합니다 (명령어·내장 함수 전체 이식)
- 이미지 지원: resources 폴더의 이미지, PRINT_IMG, HTML_PRINT 의 `<img>`, 그래픽 명령(GCREATE 등), 스프라이트, 애니메이션
- 글자 색, 버튼(탭해서 선택), 입력창(숫자/문자), 스킵 버튼, 위로 끌어서 이전 기록 보기
- BOM 없는 UTF-8 파일도 자동으로 인식
- 저장/불러오기는 게임 폴더 안에 원본 Emuera 와 같은 형식으로 저장됩니다

### 알아둘 점
- 게임 폴더를 직접 읽기 때문에 ‘모든 파일 접근’ 권한이 필요합니다
- 소리, 디버그 창 등 Windows 전용 기능은 동작하지 않습니다
- 엔진 라이선스와 변경 사항은 NOTICE 파일에 있습니다
